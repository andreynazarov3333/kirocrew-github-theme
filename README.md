# GitHub theme for Kiro Crew

A dark and light color theme for the Kiro Crew dashboard. The colors come from the
[GitHub VS Code theme](https://github.com/primer/github-vscode-theme)
(Primer primitives 7.10.0, "GitHub Dark Default" and "GitHub Light Default").

## Install

In Kiro Crew, open **Settings → Display → Theme**, press **Install Theme**, and paste:

```
https://github.com/andreynazarov3333/kirocrew-github-theme
```

Then pick **🐙 GitHub** in the theme list.

## Files

- `theme.json`: name, emoji and format version (level 0, colors only).
- `variables.json`: CSS variables for the `dark` and `light` modes.
